# Geo-Attention-PINN
Geo-Attention PINN: A Physics-Constrained Hydrocarbon Well-Site Prospectivity Prediction Method with Darcy-Type Discrete Local Flux Residuals

## Environment

The code was developed and tested using Python 3.12.

### Dependencies

- Python 3.12
- PyTorch 2.5.1
- NumPy 2.1.3
- Pandas 2.2.3
- Scikit-learn 1.5.2
- Matplotlib 3.9.2
- Seaborn 0.13.2

Install all dependencies using:

```bash
pip install -r requirements.txt
